# Подключить прокси к JetBrains Air через Goose

[English](jetbrains-air.md) · Русский

В JetBrains Air нельзя указать произвольный адрес API. Агенты в Air устроены как программы: Air сам их запускает и общается с ними по протоколу ACP. Поэтому между Air и прокси нужен агент, который понимает ACP и умеет обращаться к API Anthropic по заданному адресу. Эту роль выполняет [Goose](https://github.com/block/goose).

После настройки в Air появляется агент, который работает в открытом проекте: читает и правит файлы, запускает команды. Модель при этом выполняется через CLI `claude` под той подпиской Claude, в которую залогинен CLI.

> [!WARNING]
> Anthropic [не разрешает](https://code.claude.com/docs/en/agent-sdk/overview) сторонним продуктам без ее одобрения пользоваться входом через claude.ai и лимитами подписки. Сторонний агент на тарифе Pro или Max, подключенный через прокси, ставит аккаунт под риск.

## Как устроена связка

```
Air ──ACP──▶ goose acp ──HTTP──▶ прокси :8080 ──▶ claude CLI ──▶ подписка Claude
                 ▲                     │
                 └──── вызовы инструментов: прочитать, изменить, запустить
```

Air передает задачу Goose. Goose отправляет запрос в прокси как в API Anthropic и прикладывает список своих инструментов. Прокси запускает `claude` и передает ему эти инструменты через MCP-сервер, встроенный в прокси.

Когда модель просит вызвать инструмент, прокси возвращает вызов Goose, а процесс `claude` ждет результата. Goose выполняет инструмент в папке проекта и присылает результат следующим запросом. Прокси передает его ждущему процессу, и модель продолжает работу. Вся задача от первого шага до ответа проходит в одном процессе `claude`.

## Установить компоненты

1. Установите CLI Claude Code и войдите под своей подпиской:

   ```bash
   curl -fsSL https://claude.ai/install.sh | bash
   claude auth login
   ```

2. Установите Goose:

   ```bash
   brew install block-goose-cli
   ```

3. Соберите и установите прокси, как описано в разделе [«Быстрый старт» в README](../README.ru.md#быстрый-старт). Для сборки нужен Rust из [rustup.rs](https://rustup.rs).

## Запустить прокси

Прокси должен работать все время, пока в Air используется агент. Запустите его в отдельном окне терминала:

```bash
claude-max-api
```

Если прокси собран командой `cargo build --release`, а не установлен через `cargo install`, бинарный файл лежит в папке репозитория: `target/release/claude-max-api`.

Прокси слушает `127.0.0.1:8080`. Проверить, что он запущен, можно запросом к `/health`:

```bash
curl http://127.0.0.1:8080/health
```

В ответе должно быть `"status":"ok"`.

## Добавить агента в Air

Откройте *панель задачи > выбор агента > Add ACP Agent*. Air откроет файл `acp.json`, на macOS это `~/Library/Application Support/JetBrains/Air/acp.json`. Замените содержимое файла и сохраните его:

```json
{
  "agent_servers": {
    "Claude Code Proxy": {
      "command": "/opt/homebrew/bin/goose",
      "args": ["acp"],
      "env": {
        "GOOSE_PROVIDER": "anthropic",
        "GOOSE_MODEL": "sonnet",
        "ANTHROPIC_HOST": "http://127.0.0.1:8080",
        "ANTHROPIC_API_KEY": "sk-local-proxy-key"
      }
    }
  }
}
```

После сохранения агент `Claude Code Proxy` появляется в списке агентов Air.

| Поле | Значение | Назначение |
|---|---|---|
| `command` | Путь к `goose` | Полный путь показывает команда `which goose`. При установке через Homebrew на Apple Silicon это `/opt/homebrew/bin/goose` |
| `args` | `["acp"]` | Запускает Goose как ACP-агента, который общается с Air через stdin и stdout. Команда `goose serve` вместо этого поднимает сетевой сервер, и ответа от него Air не получит |
| `GOOSE_PROVIDER` | `anthropic` | Goose обращается к прокси по протоколу Anthropic |
| `GOOSE_MODEL` | `sonnet` | Модель Claude: `sonnet`, `opus`, `haiku` или `fable`. Модели `opus` и `fable` расходуют лимит подписки быстрее |
| `ANTHROPIC_HOST` | `http://127.0.0.1:8080` | Адрес прокси. Переменную `ANTHROPIC_BASE_URL` Goose не читает |
| `ANTHROPIC_API_KEY` | Любая строка | Прокси ключ не проверяет |
| `GOOSE_MODE` | `approve` или `auto` | Необязательное поле. С `approve` Goose спрашивает подтверждение перед действиями, с `auto` выполняет их сразу |

## Работать с агентом

Выберите агента `Claude Code Proxy` в списке агентов и поставьте задачу в открытом проекте. Goose выполняет команды в папке проекта, который передал ему Air.

Конкретная формулировка выполняется быстрее расплывчатой. На запрос «исправь опечатку в `src/main.rs`» модель сразу открывает нужный файл. На запрос «найди, где ошибка» она может запустить поиск по всему диску, и такая команда выполняется минутами.

## Проверить работу по логу прокси

Каждая задача оставляет в логе прокси похожие строки:

```
Anthropic messages model=sonnet stream=true turns=1 tools=18
Spawning claude model=sonnet api=anthropic session=fresh tools=on
Waiting for the client to run 1 tool call(s)
Continuing a parked turn with 1 tool result(s)
```

| Строка | Что означает |
|---|---|
| `tools=18` | Goose передал свои инструменты. Их число зависит от версии Goose и включенных расширений |
| `Spawning claude … tools=on` | Прокси запустил `claude` с инструментами Goose |
| `Waiting for the client to run …` | Модель вызвала инструмент, процесс `claude` ждет результата от Goose |
| `Continuing a parked turn …` | Goose прислал результат, работу продолжает тот же процесс `claude` |

Расход подписки показывает поле `rate_limits` в ответе `/health`: доля израсходованного лимита за пять часов и за неделю, а также время сброса каждого окна.

## Решить типичные проблемы

| Признак | Причина | Решение |
|---|---|---|
| Ответ в Air не приходит, индикатор загрузки не исчезает | В `args` указан `serve` | Замените на `["acp"]` |
| В логе прокси не появляются новые строки | Прокси не запущен, или в `env` задан `ANTHROPIC_BASE_URL` | Запустите прокси и укажите адрес в `ANTHROPIC_HOST` |
| В логе есть `Ignoring client tools`, агент не меняет файлы | Запущена сборка прокси без поддержки инструментов | Обновите и пересоберите прокси |
| Агент возвращает ошибку `Unknown model` | В `GOOSE_MODEL` указана модель, которую прокси не принимает | Укажите `sonnet`, `opus`, `haiku`, `fable` или полный id модели Claude |
| Ошибка с кодом 429 | Исчерпан лимит подписки | Дождитесь сброса окна, время сброса есть в `/health` |

## Обновить прокси

Загрузите изменения и пересоберите прокси:

```bash
cd claude-max-api-proxy-rs
git pull
cargo install --path .
```

После пересборки перезапустите прокси. Air перезапуска не требует.

## Ограничения

На каждом шаге задачи Goose отправляет всю историю диалога и описания своих инструментов. Поэтому агентная работа расходует лимит подписки заметно быстрее обычного чата.

Результата инструмента процесс `claude` ждет до 30 минут. Если за это время Goose его не прислал, например задачу отменили, прокси останавливает процесс.

Параметры генерации из запроса, например `temperature` и `max_tokens`, до модели не доходят: их выставляет CLI.
